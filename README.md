# Subnet Calculator

A command-line subnet calculator, built while studying for CCNA.

Given an IP address and CIDR (e.g. `192.168.1.0/24`), it prints:
- Network address
- Broadcast address
- Usable host range
- Subnet mask
- Number of usable hosts

## Usage

```bash
python subnetcalc.py 192.168.1.0/24
```
